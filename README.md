# Transformer

В этом репозитории реализован baseline GPT модели.
При реализации активно использовалась информация из книги С. Рашки "Строим LLM с нуля". Некоторые фрагменты кода были написаны нейросетью.

GPT реализован в виде python пакета. Для просмотра можно посмотреть примеры юпитер-ноутбуков ниже, либо подключить пакет напрямую

ТОКЕНИЗАТОР: при данной реализации текенизатор не реализован самостоятельно, а взят готовый с huggingface llama-2

ВАЙБКОДИНГ: некоторые фрагменты кода были написаны нейросетью, некоторые были взяты из книги Рашки. Но не один фрагмент не был вставлен без понимания. Все комментарии были написаны человеком
## 1. Запуск модели.ipynb
В этом ноутбуке можно запустить модель из python пакета, загрузив в нее веса из .pth файла

## 2. Обучение модели.ipynb
В этом ноутбуке можно обучить модель на текстах из датасета wikitext-103 и выгрузить веса в .pth файл

## 3. Использование Python пакета transformer_lab

GPT реализован в виде python пакета.

```bash
pip install git+https://github.com/tereshkovyv/transformer_lab
```

## 4. Состав модуля

### model

**attenеion.py** - блок внимания с RoPE

**feed_forward.py** - здесь реализован feed forward слой SwiGLU

**layer_norm.py** - слой нормализации через RMSNorm

**transformer_block.py** - весь блок трансформера с шорткатами

**gpt_model.py** - сама GPT модель

**generate.py** - методы генерации

### training
**data.py** - в нем есть класс TokenDataset - который можно просто брать и использовать(там внутри датасет **wikitext-103**) все берется с HuggningFace., ничего самостоятельно не реализовывал

**train.py** - код обучения модели
